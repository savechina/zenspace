## Vision

### 10x Check
OpenKB 的核心论点："传统 RAG 每次查询从零重发现知识；OpenKB 把知识编译一次成持久 wiki，然后保持更新。" zen 已有更强的检索层（5 层 + RRF vs OpenKB 的零向量押注），真正的差距在编译卫生：链接可证明、成本可预算、坏编译可回滚、质量可度量。12 个月理想态：inbox → 自编译 wiki，每页链接可证明、每页可溯源、蒸馏成本有缓存折扣、崩溃可恢复、skill 触发有分级评估。

## Test Strategy（每项随 PR 交付，bin/test 门禁）
**评估门禁（2A 决策 2026-09-27 eng 评审）：②③ 属 LLM/prompt 变更 — 两 PR 必须附带 `zen discover arena` 蒸馏回归对比结果（vs baseline，无退化才合）。**
1: okf_missing_field 报告/旧页兼容测试; 2: 白名单构建(空 wiki/含 create)/ghost 剥离(NFC 变体)/审计行测试; 3: trait 默认 no-op + anthropic 标记位置 + 非 anthropic 剥离测试; 4: 崩溃回放测试（kill 点两类：写入中途 / 写入后 commit 前 — 后者全量回滚属正确事务语义需显式钉住；替代 test_recover_is_stub）; 5: grader 双指标 + NotEvaluated 降级测试; 6: 分段阈值/切页失败回退全文测试; E1: 重叠分析决策记录 + lint agent 输出测试; E2: sources 写入/LLM 覆写防护/级联清理测试; E3: 级联剥除/孤儿删除/链接清理测试。

## Config Surface（5-layer 惯例，全部 clamp + env）
[agentic.compile] ghostlink_enforcement(warn|strip, 默认 strip), okf_lint(bool, 默认 true); [agentic.cache] breakpoints(bool, 默认 true—仅 anthropic 生效); [agentic.loop] tree_index_pages(默认 20, clamp 5..=200); E1 [agentic.lint] semantic(bool, 默认 false—重叠分析后才开)。journal 不设开关 — journal 即 .txn-{name}.jsonl 追踪文件本身（复用 distill txn 生命周期，非新概念）；journal/txn 文件纳入 RetentionWorker 清理策略（rotate@5MiB keep-2, 对齐 loop-gaps 惯例）。

## Acceptance Metrics（每项一个可度量验收）
1 OKF: lint 报告缺失字段数=可解释为零（存量页一次性迁移后）; 2 ghost: 编译产物零断链（lint 断链计数 delta ≤ 0）+ 审计行 ghostlinks 计数; 3 cache: 重复编译请求 cache_creation_input_tokens 占比可观测（审计行/usage 透出）; 4 journal: 注入 kill 后重放=文件集恢复一致（测试钉住）; 5 eval: confirmed skill 100% 有 trigger/body 分数（或显式 NotEvaluated）; 6 tree: ≥阈值文档索引构建耗时 < 全文路径 p50; E1: 决策记录合并 + semantic lint 默认 false 开关翻转需记录; E2: 新编译页 100% 带 sources（lint 报告=0）; E3: 删源后编译页引用计数归零（测试钉住）。
